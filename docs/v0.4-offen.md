# v0.4 – offene Punkte

Arbeitsliste für den Branch `feature/v0.4`. Erledigtes wird abgehakt, damit eine
neue Sitzung (oder eine andere Person) jederzeit weitermachen kann.

## Erledigt
- [x] Modi «Entwurf» und «Simulation» (Dokumentation im Entwurf integriert), neue Session startet leer
- [x] Menüleiste im macOS-Stil, Befehlspalette (Strg+K), Tastenkürzel, F1-Hilfe
- [x] Funktionsprofile 1–5, eigene Auswahl, Funktionsdatei mit Sperre, Admin-Richtlinie
- [x] Shop mit Kategorien, Varianten, Anschlüssen, SFP-Modulen, Richtpreisen
- [x] Kostenmodell CHF/EUR/USD, Kostendialog, Prüfbaustein «Budget»
- [x] Server-Gerät (DHCP/DNS/Web/Mail), Client-Gruppen mit DHCP
- [x] WLAN-Roaming mit Reassociation und Gratuitous ARP
- [x] Serielle Ports (HDLC/PPP mit LCP/IPCP)
- [x] Statisches NAT (SNAT/DNAT, Proxy-ARP), CGNAT beim Provider
- [x] OSPF, RIP v2, BGP-4 (binär nach RFC 4271), administrative Distanz
- [x] Modems: DOCSIS, GPON, LTE, ADSL, VDSL mit Zugangsablauf
- [x] Broadcast-Sturm-Erkennung, Schleifen ohne STP erlaubt mit Warnung
- [x] Kodierung mit echten Bytes, pcapng-Export
- [x] Sniffer: OSI-Ansicht 7→1, Hex-Ansicht, Filtersprache, Schnellfilter
- [x] IP-Rechner mit Übernehmen
- [x] Snapshots alle 5 Minuten (nur bei Änderungen)
- [x] Neue Prüfbausteine im Aufgabeneditor
- [x] Texte de/en inkl. F1-Hilfe
